Need to know

Frequently asked questions.

Which Minecraft editions are supported?

Java Edition and Bedrock Edition crossplay are intended to be supported through GeyserMC. Java version compatibility depends on the server's installed ViaVersion and related configuration.

How do I join NEBULAA SMP?

Use the Java address and port for Java Edition. For Bedrock, enter the server IP and the configured Bedrock port in the Bedrock server form.

How does the economy work?

The server includes an in-game economy and shop. Use the available in-game economy and shop commands to check current prices and balances.

How do bounties work?

Bounties are a server feature. Check the in-game bounty commands or ask a staff member for the current command syntax and rules.

What are the server rules?

Please follow the rules posted by the server owner or staff in-game or in the server's official community channels.

How do I get support?

Contact a server staff member or the owner through the support channel made available by the server team.
